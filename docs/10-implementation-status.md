# 工程实现状态

更新时间：2026-07-29

## 已完成

- 建立 Java 21、Spring Boot 3.5.3、Maven 后端工程。
- 建立 Vue 3、TypeScript、Vite、Element Plus 前端工程。
- 使用 PostgreSQL 和 Flyway 建立组织、部门、用户、角色、权限、数据范围及审计模型。
- 实现数据库用户认证、BCrypt 密码校验、JWT 访问令牌和方法级权限校验。
- 实现登录成功/失败审计与关键管理操作审计。
- 实现部门完整增删改查。
- 实现用户增删改查、启停、重置密码和角色分配。
- 实现角色增删改查、权限分配和数据范围配置。
- 实现权限项完整增删改查。
- 前端已完成真实后端登录，以及部门、用户、角色、权限管理页面联调。
- 修复逻辑删除用户后残留角色关联的问题；角色删除会清理用户、权限及数据范围关联。
- 新增 Flyway V4 一期业务领域迁移，覆盖财务、物料、文件和分析报告核心数据模型。
- 财务管理已实现价目、费用试算、收费单确认、部分/全额收款、欠款与成本汇总。
- 价目管理已实现新增、修改和删除；被收费单引用的价目在前端置灰并由后端强制禁止修改、删除。
- 财务状态已统一中文展示，新建收费单只允许选择启用状态的检测价目。
- 待确认收费单支持修改、删除和确认；未收款的待收款收费单支持退回待确认并重新编辑。
- 财务页面入口已按页签归位：新建收费单位于收费单与收款页签，新增价目位于价目管理页签。
- 物料管理已实现物料档案、供应商、采购申请审批、批次入库、领用出库、库存流水和效期/低库存预警。
- 物料危险属性、采购状态、库存业务类型及方向已实现英文编码存储、中文界面展示。
- 物料管理页签按“物料档案、采购与入库、物料信息库、库存流水”排序；点击物料管理菜单时默认打开物料信息库。
- 物料信息库已提供组合查询、查询结果 Excel 导出和打印，并调整验收入库、领用出库按钮顺序与配色。
- 物料信息库工具栏已完成查询、导出、打印和重置联动；重置可清除筛选并恢复全部记录。
- 物料数量为零时显示“无库存”并整行置灰，无库存批次不可再次领用出库。
- 物料档案已增加修改和删除操作，修改复用新增表单；物料一旦存在于物料信息库或采购申请中，后端禁止删除，前端删除按钮同步置灰并通过悬停提示具体引用原因；仅未被两类业务引用的物料允许删除。
- 采购申请列表已展示物料编码；页签内采购申请按钮与新增物料按钮尺寸统一，提交、通过、退回操作采用大号醒目实体按钮。
- 草稿采购申请支持二次确认后删除；待审批申请退回后恢复为草稿状态，可再次提交，不再进入已退回终态。
- 采购申请页右侧提供“导出采购清单”功能，仅将状态为已通过的采购申请导出为 Excel；无符合记录时给出提示。
- 验收入库入口已移至已通过采购申请的操作列；验收信息提交后进入待入库审核，通过时才写入物料信息库及库存流水并标记已入库，退回时恢复为已通过状态以便重新验收。
- 采购审批和入库审核的通过按钮分别显示为“申请通过”和“入库通过”，明确区分两个审批阶段。
- 文件管理已实现受控文件、版本历史、提交审核、退回、审核通过、发布、替代、作废和复审提醒。
- 分析报告已实现内置模板、报告编制、预览、提交、审核、批准、发放、归档、哈希固化及职责分离。
- 四个业务模块前端已从演示数据切换为真实后端 API 和可操作表单。
