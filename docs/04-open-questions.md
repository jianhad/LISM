# 待确认问题

以下问题会直接改变系统设计。P0 应在详细设计和业务编码前确认；P1 可在对应模块开发前确认。

## 已确认事项

- 一期采用建议范围。
- 系统部署在内网并要求国产化。
- 预计用户不超过 100 人，要求支持不少于 200 人并发访问。
- 一期无电子签章、短信、邮件、统一登录或财务系统对接。
- 必须建设完整权限管理模块。
- 当前无法提供业务单据和报告模板。

## P0：范围与部署（剩余）

1. 指定的国产 CPU、操作系统、数据库、中间件和浏览器品牌及版本是什么？
2. 预计年业务量、报告数、附件容量分别是多少？
3. 是否有必须迁移的历史数据？来源是旧系统、Excel、Access 还是纸质记录？
4. 数据保存年限、备份频率、允许的数据丢失量（RPO）和最长恢复时间（RTO）是多少？

## P0：业务与合规

5. 请提供现行组织架构、岗位、签字授权范围和权限审批制度。
6. 请确认本文设计的财务、采购入库、领用、文件发布和报告审核流程能否作为一期默认流程。
7. 报告的审核级数、批准条件、撤回/更正规则和编号规则是什么？
8. 哪些数据一经审核不得修改？发现错误时采用退回、作废重开还是更正单？
9. CMA/CNAS 评审所要求的具体记录、保存期限和审计导出格式有哪些？

## P1：财务与物料

13. 收费模型有哪些：按样品、项目、批次、套餐、最低收费或加急费？税费和折扣审批如何处理？
14. 收款是否需要对接财务系统或开票系统？是否允许退款、冲销和跨单核销？
15. 库存计价采用移动加权平均、批次成本还是其他方法？是否存在多仓库、多库位和多计量单位换算？
16. 危险品是否要求双人双锁、双人领用、限量、公安台账或视频记录关联？
17. 标准溶液配制、纯水核查和标准物质期间核查需要哪些模板与计算规则？

## P1：文件与报告

18. 文件版本号、审核级数、受控副本、回收、作废和定期复审规则是什么？
19. 请提供所有报告、原始记录、标签和统计报表模板，以及字段来源和计算规则。
20. 报告模板需要网页可视化拖拽编辑，还是由管理员维护 DOCX 模板即可？
21. Word、Excel、PDF 三种输出是否要求版式完全一致？生产环境是否允许安装 Office/LibreOffice？
22. 档案保存为最终文件、结构化数据快照，还是二者都保留？

## 建议用户先提供

- 组织架构与人员角色清单；
- 六类现行流程图或文字步骤；
- 典型收费单、采购申请、入库单、领用单、体系文件、检测报告样例；
- 服务器与网络部署约束；
- 一期必须上线功能和期望上线时间。
